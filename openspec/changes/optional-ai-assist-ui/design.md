# Design
A compact OptionalAssistPanel shares consent, Ask AI, Cancel and Configure AI on one row and wraps the disclosure/status beneath. OptionalAssistController snapshots context and constructs operations on the GUI thread, executes through QThread/BackgroundWorker/WorkerRegistry, then accepts token- and context-matching delivery on its QObject thread. Integration helpers inject structured services for offline synthetic tests and install panels without modifying existing screens. Editor and saved-set snapshots include current repository facts and editor revision/locks. MainWindow owns controllers and cancels before its existing thread-draining close flow.
