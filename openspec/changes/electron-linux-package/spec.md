# Requirements

- R1: GIVEN a green full aggregate report bound to the current source digest, WHEN
  packaging is requested, THEN the package can be built; failed, stale, incomplete,
  or wrong-tree evidence MUST stop before output creation
- R2: GIVEN a valid package moved to another directory and a PATH without Python or
  FFmpeg, WHEN the bundled core is started, THEN local JSONL metadata/Prep/persistence
  read-only spectral/danceability/edge completion and loudness measurement/tagging
  function using bundled dependencies
- R3: GIVEN an attempted bundle containing Qt modules/libraries, development
  dependencies, external symlinks, or a missing bundled engine, WHEN validating,
  THEN packaging fails rather than silently relying on the host
- R4: GIVEN a valid package, WHEN opened by Electron, THEN the existing hardened
  packaged executable path resolves, with local UI and original trust boundaries
- R5: GIVEN a completed build, THEN license files, exact input/runtime versions,
  source digest, FFmpeg provenance, tested Linux baseline and SHA256 are retained
- R6: GIVEN absent sandbox support, THEN no launcher disables Electron's sandbox;
  unsupported hosts fail explicitly rather than weakening renderer isolation

- R7: GIVEN an absent or hostile inherited JIT/cache setting, WHEN the packaged
  core starts with a validated canonical data directory, THEN code cache is written
  only beneath that directory, optional waveform caching remains disabled, and
  malformed arguments or symlink escapes create no cache directories

## Tagged synthetic smoke fixtures

GIVEN the unchanged metadata-first scanner skips audio without tags, WHEN the
packaged smoke runs, THEN its loudness and six-format inputs are copied tagged
synthetic fixtures; source audio hashes and decoded PCM stay unchanged during
fixture preparation. No scanner behavior changes to accommodate the harness.
