# Design
Central app draft descriptors supply labels and explicit navigation. A small shared notice renders stable buttons for loudness, deletion and the companion import unit. Action-specific preview/run eligibility leaves shared canAct and Save/Discard available. syncDraftDirty refreshes dependent views; main IPC and Serato guards remain unchanged. The preview heading uses tabindex=-1 and an accessible summary; only a new accepted preview receives focus. Tests execute the complete compiled renderer, source-extracted main dispatch guard, and real LoudnessHost with synthetic responses. Actual native viewport verification remains separate.
