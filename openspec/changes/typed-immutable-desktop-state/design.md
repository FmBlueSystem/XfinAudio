# Design
Freeze AppState dataclass fields and use dataclasses.replace for shallow checked updates; retain existing list/dict public payload compatibility. Replace helper mutations with functional returns. Introduce narrow typed current/replace state access and use it for scan progress and AppController synchronization. Legacy shell property writes map to named fields, then call shell replacement owner after initialization; explicit fallback before services exist. Getter for current scan token returns the service value without mutating snapshot. Preserve centralized existing service synchronization until a separate larger port migration is justified.
Do not touch completion batching app_state_transitions.py/library_controller.py ownership. Use offscreen integration tests plus static negative-contract fixtures and configured release gate.
