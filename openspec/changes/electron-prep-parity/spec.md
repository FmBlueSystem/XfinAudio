# Requirements

- The strategy list exactly reflects the existing domain catalog, including descriptions and prerequisite warnings
- The user can choose count, optional slot duration/role, genre, start/end track and required/excluded tracks using known track identities only
- Real existing candidate planning and Prep algorithms produce safe, balanced and adventurous alternatives; no missing analysis is fabricated
- Selecting a variant produces a fresh review identity and displayed readiness before explicit save
- New scan/generation, cancellation or stale plan/variant requests cannot save or publish an older candidate
- Default balanced behavior remains compatible with the first-slice workflow
- Unsupported strategies, non-finite/out-of-range numbers, conflicting controls and unknown track identities fail safely
- Controls remain accessible, localized and safe under repeated requests, navigation, cancellation and core disconnect
