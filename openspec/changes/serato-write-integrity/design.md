# Design
Retain the public plan/result fields and destination calculation. Validate the deterministic supported payload against independently validated relative paths. Add a typed OSError subclass for write/verification/recovery failures. Use no-follow regular-file reads, exclusive backup creation, and same-directory temporary files with flush/fsync and atomic replacement. Keep backup history rather than reusing an occupied `.bak` name. Recovery uses captured prior bytes and checks target identity before replacing/deleting; an unsafe concurrent change produces explicit manual recovery guidance. Public rollback uses the same no-follow/atomic primitives. UI already catches exceptions; no UI destination changes belong here.
