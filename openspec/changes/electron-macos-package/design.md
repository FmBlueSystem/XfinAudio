# Design

Mac-only console entry delegates canonical CLI validation/cache directory creation to unchanged Linux bootstrap, then installs a Mac-only direct app-data Numba locator before scientific imports. Inherit Numba frozen executable stamp and source disambiguation. Separate bounded Mach-O resolver copies trusted closure, rewrites loader-relative dependencies/IDs and ad-hoc integrity signs only new artifacts. Recipe reuses source seals/module/gate validation, overlays Mac entry/FFmpeg, compiles TypeScript and assembles a fresh Electron.app. Dependency probe is not an application release.
