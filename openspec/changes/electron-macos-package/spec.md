# Requirements

Given canonical isolated app data and hostile inherited cache variables, frozen Mac JIT caches stay beneath app data, with executable content-hash invalidation. A read-only HOME/bundle and relocated empty-PATH cold/warm six-format probe succeeds without Qt. Given a trusted existing FFmpeg, the recipe embeds its complete native dependency closure and only system or contained relative dependencies survive; Homebrew/venv/unresolved references fail. Given sealed complete gates, assembly uses Electron.app Contents/Resources/app and core; final app build is deferred until owner V11 authorization.

## Production executable identity

GIVEN a Mac bundle assembled from the stock Electron distribution, WHEN launched
from its original or relocated folder, THEN its main executable and plist identity
are XfinAudio Next rather than Electron, packaged mode is true without an override
variable, and the unchanged application selects its bundled Python core. All native
audits and post-signing manifests must use that same renamed executable.
