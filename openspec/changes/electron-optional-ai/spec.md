# Requirements

1. Disabled/unconfigured status is truthful and never probes credentials or contacts a provider. Settings preserve original optional NaN semantics and unrelated app preferences.
2. Only a native-selected credential-file source may be configured; no renderer path/key/endpoint/command input. Values remain out of DTOs, diagnostics and persisted app settings.
3. Read-only request preparation binds source context, settings revision, redacted request and disclosure. Changing source/request/configuration/recipient invalidates the preview and any pending result.
4. Only explicit native-confirmed requests invoke the original bounded adapters. Endpoint is the disclosed Nan Builders HTTPS service, redirects are refused, response/request limits hold and external text stays untrusted.
5. Library/Prep/editor/saved-set proposals require local review then explicit Apply; Apply uses existing local validation and never automatically saves/exports/writes audio. Review/metadata/Live narration is commentary only.
6. Cancellation and core disconnect never revive stale results. Already-sent data cannot be recalled and the UI says so. All tests use isolated dummy configuration/fake transport; no actual external request or credential inspection.
7. The new executable/environment remains Qt-free; the neutral LibraryQuery model retains the original Qt facade.

## Corrective acceptance scenarios

- GIVEN assistance has never been used, WHEN the app starts, scans/rescans, invalidates a loudness request or performs a safe local Serato export, THEN it does not import the optional provider package or instantiate its facade.
- GIVEN a native-selected credential file disappears or native selection fails, WHEN selection completes, THEN the renderer receives only a bounded credential-unavailable error, with no selected absolute path or raw filesystem exception.
- GIVEN locally selected opening/closing, required and excluded tracks, WHEN an AI Prep proposal is applied, THEN local boundaries take precedence and required/excluded controls are retained. Contradictory resulting controls are rejected before any form field changes or generation.

- GIVEN a completed result, WHEN a different normalized request, surface, context or invalid prepare input supersedes it, THEN the old result cannot apply or revive after switching back. Bounded history may be reused only for an identical immutable reference.
- GIVEN Metadata has no authoritative locked-track selection, WHEN preparing an explanation, THEN no locked-gap count is supplied and the disclosure states this priority is unavailable; legacy callers with known counts retain their facts.
- GIVEN a trusted assistance surface, WHEN it invokes its provider adapter, THEN its finite timeout policy is at most 60 seconds for Prep, 120 for Review, 10 for connection, and 30 for the other surfaces. Renderer-provided timeout overrides are rejected.
