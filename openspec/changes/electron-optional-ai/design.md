# Design

Move the existing pure LibraryQuery/parser into the application package with a legacy facade. Extend the shared bounded preferences service with nonsecret AI settings and a main-only credential-source mutation; avoid adapter configuration-status helpers that inspect operator environment or credentials during page load.

A headless optional-assistance facade composes existing interpreter/narrator functions behind immutable request previews, settings/source revisions, a fixed disclosed endpoint and bounded transport. Main owns native file selection and per-request confirmation. Renderer gets opaque preview IDs, recipient/data disclosures and validated proposals/commentary, never key values or paths.

A common renderer controller/view manages unchecked consent, preview/ask/cancel, stale context, error normalization and explicit Apply. Each surface supplies its current local context and its already-existing application operation. Missing metadata remains unknown and local musical validators remain authoritative. Connection tests are explicit requests and are mocked in this migration.

The dispatcher imports only provider-free AI command shapes. A lazy facade property preserves the transport-injection seam; baseline invalidation checks the already-created instance without initializing it. Native picker failures are normalized before crossing IPC. Prep Apply merges local hard controls using the original confirmed-intent precedence, validates the full merged form, and only then changes local fields.

New preparation revokes consent, results and the in-flight epoch before input validation; a successful preparation restores only cached results with an identical normalized immutable reference. Metadata lock counts are optional evidence: unavailable counts are omitted, with no invented zero or evaluated-priority claim. Immutable provider-free timeout policy is selected by the validated surface; the adapter and bounded transport preserve the original Prep/Review budgets without accepting renderer override values.
