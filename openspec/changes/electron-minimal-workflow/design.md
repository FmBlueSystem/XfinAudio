# Renderer-only design

Keep internal routes and mounted forms. Native details expose optional controls. A reveal helper opens every details ancestor and focuses the real input; invalid events and semantic errors use it. Preserve buildPrepInput and engines. Minutes always retain the count cap, no sizing algorithm change.

Existing GeneratedReview and Serato controllers remain unchanged. Views retain selection/disclosure identity and expose only the next explicit export action. Tool origins record actual entry; Back avoids recording a reverse edge and restores a mounted trigger or main-content fallback. Known readiness/variant UI is Spanish; original facts remain available, with blockers visible.

AI remains one instance with eight surface mappings. Provider settings live in Settings; contextual help opens the same panel without preparing/sending. Settings/Prep summaries distinguish draft and persisted state.

Tests parse actual shipped HTML for IDs/ancestry/order and use bounded mocked app/view behaviors. Fake DOM does not establish native layout, constraint-validation timing, keyboard focus order, accessibility or pixel visibility. Parent owns exact-source native checks and combined Python gate. All new recovery edits must be reverified.
