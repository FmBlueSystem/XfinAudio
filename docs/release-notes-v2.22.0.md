# XfinAudio 2.22.0 Release Notes

Date: 2026-11-21

## Summary

2.22.0 is an **unreleased beta/source candidate** built on 2.21.0. The app now
carries the brand that publishes it: **BlueSystemAudio**.

## Brand

- The sidebar signs the app «by BlueSystemAudio» under its name, with «Blue» in
  the brand's blue.
- The system About panel names XfinAudio, its version and «by BlueSystemAudio».
- The wordmark is kept as `docs/brand/bluesystemaudio.svg`.

The app's name, data and behaviour do not change.
