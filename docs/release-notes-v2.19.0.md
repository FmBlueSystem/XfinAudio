# XfinAudio 2.19.0 Release Notes

Date: 2026-11-21

## Summary

2.19.0 is an **unreleased beta/source candidate** built on 2.18.0. On the Live
screen you now choose, with a click, which Serato deck the suggestions are for.

## Choose the deck

Serato records a track when it is loaded on a deck, not when it is heard, so the
most recently loaded deck is not always the one that is playing. In **Sonando en
Serato** each deck is now a button:

- Click a deck and the suggestions are for the track on that deck. The deck is
  marked **Actual** and the table is headed «Qué poner después de title».
- The choice stays: when another track is loaded on that deck, the suggestions
  follow it.
- **Automático** returns to the most recently loaded deck.

A chosen deck with nothing loaded, or with a track that is not in the library,
shows the usual message and no suggestions.

## Compatibility

No stored data changes. The choice lasts while the Live screen is open.
